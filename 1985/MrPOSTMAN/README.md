# Mr.POSTMAN

## 動画URL

https://youtu.be/J4vHpH6UfAk


## 動作条件

- メモリは16KBです。
- ページ数は2です

## プログラムの起動方法

プログラムは  
P6_MrPOSTMAN_16k_p2.wav １つのみです。

起動～ロード～ゲームメインまでの手順はこんな感じです。

- カセットケーブルの白をwav再生デバイスと接続します
- PC6001実機を起動します
- How Many Pages? は2を指定してください
- ***CLOAD***コマンドを実行します
- wav再生デバイスで`P6_MrPOSTMAN_16k_p2.wav`を再生します
  - `POST` という名前で読み込まれます
- ***RUN***コマンドでプログラムを実行します
- タイトル画面で`SPACE`キーを押すと、ゲームが開始します。
- ゲーム中は、カーソルキーでポストマンを操作します
- ゲーム中に`SPACE`キーを押すとギブアップになります

### ゲームの説明

エリアにあっちこっちに落ちている４枚のはがき集めて
ポストに持っていくパズルゲームです。

<img src="images/screenshot01.png" />

・アイテムに重なるとそのアイテムを取ります。
・取ったアイテムは４つまで持つことができます。
・４つ持っている時にアイテムを取ると、最初に取ったアイテムを手放します。
・はがきを４つ持った状態でポストに当たるとクリアになります。
・はがき以外の同じアイテムを４つ持つと失敗となります。
・乾電池を１つでも持つと失敗となります。

ステージは１丁目から３丁目まであります。
